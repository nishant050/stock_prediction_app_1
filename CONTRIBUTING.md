Thanks for your interest in contributing! Please follow these guidelines:

1. Fork the repository and create a new branch for your work.
2. Make small, focused commits and add tests for new features/bugs.
3. Do not commit secrets or API keys. Use `.env` or GitHub Secrets in CI.
4. Ensure all tests pass locally before creating a PR.
5. Run code style checks and flake8 before pushing.

If you need help setting up the project locally, check the instructions in the `README.md`.
